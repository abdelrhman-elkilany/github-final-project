# GitHub Final Project – Simple Interest Calculator

This repository contains a Bash script that calculates **Simple Interest** based on user input.  
It is created as part of the GitHub Final Project.

## Description

The Simple Interest Calculator helps users compute the interest on a principal amount using the formula:

Simple Interest = (Principal × Rate × Time) / 100

The script takes three inputs from the user:
- Principal amount
- Rate of interest (in percentage)
- Time period (in years)

It then calculates and displays the simple interest value.
